# Psiphon Core GUI Client

یک رابط گرافیکی با استفاده از PySide6 برای مدیریت و مانیتورینگ مستقیم هسته سایفون (`psiphon-tunnel-core`).

## ویژگی‌ها
- نمایش زنده و رنگی لاگ‌های هسته سایفون
- تفکیک دقیق وضعیت اتصال، جستجوی سرور و پورت‌های مپ شده
- قابلیت تولید و باز کردن مستقیم لینک پروکسی برای تلگرام (SOCKS5)
- پشتیبانی از حالت تاریک (Dark Mode) و اسکرول خودکار لاگ‌ها

## نیازمندی‌ها
- پایتون ۳.۱۰ یا بالاتر
- باینری کلاینت هسته سایفون (`psiphon-tunnel-core-x86_64`)

## نحوه اجرا

۱. ابتدا نیازمندی‌های پایتون را نصب کنید:
```bash
pip install -r requirements.txt
```

۲. پروژه را اجرا کنید:
```bash
python psiphon_gui.py
```
